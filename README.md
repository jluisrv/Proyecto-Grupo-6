# Proyecto IoT - Grupo 6

Sistema de Internet de las Cosas (IoT) para adquisición de datos, almacenamiento en serie temporal, análisis mediante Machine Learning y visualización.

## 📂 Estructura del Repositorio
* **firmware/**: Código para los dispositivos de hardware / microcontroladores.
* **backend/**: Servidor y lógica de procesamiento de datos.
* **ml-anomalias/**: Modelos de Machine Learning para detección de anomalías.
* **ml-vision/**: Modelos de Machine Learning orientados a visión artificial.
* **dashboard/**: Interfaz visual / panel de control para el usuario.
* **docs/**: Documentación técnica, diagramas y guías del proyecto.

## 🚀 Flujo de Trabajo
Este proyecto utiliza el flujo `main` → `develop` → `feature/*`. Ningún cambio se sube directamente a `main` sin pasar por un Pull Request aprobado hacia `develop`.
